# TCT365 Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (người dùng chọn triển khai ngay trong phiên). Steps dùng checkbox.

**Goal:** Landing page Next.js mới cho TCT365 + blog có trang quản trị, deploy Vercel không cần sửa code.

**Architecture:** Next.js 15 App Router (JS). Nội dung tĩnh trong `data/`. Bài viết = Markdown, nguồn kép: `content/posts` (repo) + Vercel Blob (khi có token) hoặc fs (local). Admin xác thực bằng cookie HMAC ký bằng `ADMIN_PASSWORD`.

**Tech Stack:** next 15, react 19, @vercel/blob, marked, @playwright/test.

**Spec:** `docs/superpowers/specs/2026-10-17-tct365-website-design.md`

## Global Constraints
- Chỉ Node/JS; không TypeScript, không Tailwind, không thư viện 3D.
- Không bịa số liệu: thiếu → `[CẦN BỔ SUNG]`. Không dùng giá/thời hạn cũ năm 2023, không tên cơ quan đã sáp nhập (Sở KH&ĐT, UBND cấp huyện) → "cơ quan đăng ký kinh doanh".
- Địa chỉ: `432 Phạm Văn Đồng, Phường Đông Ngạc, TP Hà Nội`. Không có "Ban lãnh đạo", không có "Kim Mã".
- Màu: teal `#036B68`, gold `#D99A2B`. Tôn trọng `prefers-reduced-motion`.
- `npm run build` phải thành công khi KHÔNG có biến môi trường nào.

## Review Focus
1. Không có `ADMIN_PASSWORD` → `/admin` hiện hướng dẫn, API trả 503, build không lỗi → test e2e chạy server không env? (test bằng unit `lib/auth.test.js`: `verifyToken` false khi thiếu mật khẩu).
2. Slug tiếng Việt có dấu/ký tự lạ → `slugify` bỏ dấu, `đ→d`, chỉ `[a-z0-9-]` → unit test.
3. Slug trùng với bài có sẵn → API tạo bài trả 409 nếu tạo mới trùng slug.
4. Cookie giả/hết hạn → bị từ chối → unit test `verifyToken`.
5. Thư mục `public/clients` có file không phải ảnh (Thumbs.db, .DS_Store) → bị lọc.

### Task 1: Scaffold + dữ liệu + lib (TDD cho lib)
**Files:** `package.json`, `next.config.mjs`, `jsconfig.json`, `.gitignore`, `.env.example`, `data/site.js`, `data/services.js`, `lib/slugify.js`, `lib/auth.js`, `lib/posts.js`, `lib/clients.js`, `tests/unit.test.mjs`
**Interfaces (Produces):**
- `slugify(str) → string`
- `signToken(password, now=Date.now()) → string`, `verifyToken(token, password, now=Date.now()) → boolean`, `isAdmin() → Promise<boolean>` (đọc cookie `tct_admin`)
- `getPosts() → Promise<Post[]>` (mới nhất trước), `getPost(slug) → Promise<Post|null>`, `savePost({slug,title,date,category,excerpt,cover,body}) → Promise<void>`, `deletePost(slug) → Promise<void>`, `saveUpload(file) → Promise<string url>`; `Post = {slug,title,date,category,excerpt,cover,body,source:'repo'|'store'}`
- `parsePost(md, slug) / serializePost(post)` frontmatter tối giản.
- `getClientLogos() → {src, name}[]`
- [ ] Viết `tests/unit.test.mjs` (node:test) cho slugify, signToken/verifyToken, parse/serialize, lọc logo → chạy `node --test` FAIL → implement → PASS → commit.
